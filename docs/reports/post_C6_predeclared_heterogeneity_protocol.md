liquidity weighting is used.

### 11.1 Categorical comparison

For category shares `p_j` in the provisional set and `q_j` in the accepted
reference population, over the union of categories:

```text
TOTAL_VARIATION_DISTANCE =
0.5 * SUM_j ABS(p_j - q_j)
```

TVD is descriptive only. No TVD threshold is used to classify the set or
produce an Owner governance label.

### 11.2 Numeric comparison

For the required liquidity dimension, and for optional market capitalization
only when a valid accepted PIT source exists, execution may report each subject
value's empirical percentile position in the accepted reference distribution.

For subject value `x_i` and reference population size R:

```text
EMPIRICAL_REFERENCE_PERCENTILE_i =
COUNT(reference_value <= x_i) / R
```

Report the three percentile positions in accepted subject order and their
median. Ties are handled deterministically by the `<=` definition.
